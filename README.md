## Como Usar?

### Localmente

Se instalar o pacote npm localmente em uma pasta, você deve rodar o pacote com o seguinte comando:

```
npm run contador
```

Ele pegará o documento .txt que tiver com a palavra "todo" no nome.

### Globalmente

Se instalar o pacote npm globalmente em seu computador, você deve rodar o pacote com o seguinte comando:

```
contador
```

Ele pegará o documento .txt onde o pacote foi executado que tiver com a palavra "todo" no nome.

### Remoto

Se não quiser instalar o pacote no seu computador, pode executar através do seguinte comando

```
npx contador-de-metas
```

Ele pegará o documento .txt onde o pacote foi executado que tiver com a palavra "todo" no nome.
